# Hyprland seed config

User-overridable Hyprland configuration. Sources the compositor-level
defaults at `/etc/aurum/hypr/aurum.conf` (shipped by
[`distro/hyprland-fork/`](../../hyprland-fork/README.md)) and adds the
keybindings, autostart, and input settings the user is expected to tweak.

- `hyprland.conf` — bindings, exec-once, env, input/touchpad
- `wallpaper.sh` — swww-preferred wallpaper engine (swaybg fallback)
