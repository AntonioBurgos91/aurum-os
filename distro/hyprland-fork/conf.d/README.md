# /etc/aurum/hypr/conf.d/

Drop-in directory for per-app Hyprland rules added by Wave 8 / Wave 9 agents.
`aurum.conf` includes this directory via:

```
source = /etc/aurum/hypr/conf.d/*.conf
```

so each new agent can ship its own `*.conf` (window rules, layer rules,
keybinds) without colliding with `aurum.conf` itself.

## Convention

| Filename                  | Owner                              |
|---------------------------|------------------------------------|
| `10-vllm.conf`            | Wave 8 vLLM agent                  |
| `15-comfyui.conf`         | Wave 8 ComfyUI agent               |
| `20-continue.conf`        | Wave 8 Continue.dev agent          |
| `25-langfuse.conf`        | Wave 8 Langfuse agent              |
| `90-user-overrides.conf`  | Reserved for user-local overrides  |

Two-digit prefix orders the load. Lower wins for matchers that fall through;
higher overrides for matchers that re-declare the same key.

## Don't

- Edit `aurum.conf` directly — that file is owned by the Hardware Profile
  agent (Agent G, Wave 8) and is regenerated by the ISO builder.
- Use a class catch-all (`match:class ^aurum-.*$`) — see the note in
  `aurum.conf` about ordering blowing up existing applets.
