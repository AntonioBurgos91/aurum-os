# AurumOS Desktop Custom Themes

To achieve visual consistency with macOS Sequoia across all widget toolkits, we ship optimized themes for GTK and custom icon assets.

## Structure
- **gtk4**: Custom fork of the WhiteSur GTK theme tailored for clean backgrounds without rendering overhead.
- **icons**: WhiteSur Icon Theme with modifications for machine learning applications (e.g., custom icons for JupyterLab, Marimo, TensorBoard, and PyTorch).
