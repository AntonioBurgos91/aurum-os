# AurumOS — Python DL stack, CPU-installable subset.
#
# Use case: dev containers without nvcc, CI smoke runs, and AurumOS targets
# without an NVIDIA toolkit installed (rare but possible — e.g. AMD-only
# workstations using rocm.list instead of dl.list).
#
# The packages omitted vs pip-requirements.txt (and why):
#   * vllm           — requires nvcc at wheel-build time
#   * triton         — wheel availability lags behind cpython releases
#   * bitsandbytes   — ships CUDA bytecode in its wheel; refuses non-CUDA host
#
# Production ISO calls pip-requirements.txt (the full set). The chroot has the
# CUDA toolkit installed by 01-add-nvidia-repo.sh before this runs.
