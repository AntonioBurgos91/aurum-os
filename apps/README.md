# AurumOS Applications and User Shell Environment

This directory holds the configurations and integration scripts for developer apps pre-packaged with the system.

## Inclusions
- **terminal-tweaks**: Tailored setups for:
  - **Ghostty**: Modern GPU-accelerated terminal with custom window transparency and color palette.
  - **Fish 4.0**: Fish shell configs utilizing Starship prompt and keybind overrides (such as remapping command key chords).
  - **Zellij**: Configuration layout matching our macOS-like tiling style.
